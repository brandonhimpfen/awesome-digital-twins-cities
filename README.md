> A curated list of resources for urban digital twins, 3D city modeling, spatial data integration, urban simulation engines, and smart city visualization platforms.

Urban digital twins integrate 3D spatial models, real-time IoT sensor streams, building information modeling (BIM), and geospatial simulation engines to model, analyze, and optimize city infrastructure and urban environments. This list is intended for urban planners, GIS specialists, smart city engineers, software developers, and spatial data architects.

## 3D City Modeling & Data Standards

Open data formats, schema specifications, and conversion toolkits for capturing, storing, and exchanging semantic 3D city models.

- [CityGML](https://github.com/citygml) — Open spatial data model and XML-based format defined by the OGC for representation, storage, and exchange of virtual 3D city models.
- [CityJSON](https://github.com/cityjson/cityjson) — JSON-based alternative schema for CityGML designed to be lightweight and easy to parse in web environments.
- [3D Tiles](https://github.com/CesiumGS/3d-tiles) — Open specification by Cesium for streaming massive 3D geospatial datasets including photogrammetry, BIM models, and 3D buildings.
- [py3dtiles](https://github.com/py3dtiles/py3dtiles) — Python library for generating, manipulating, and converting point clouds and 3D city assets into 3D Tiles format.

## Visualization & Rendering Engines

Web-based 3D engines, geospatial GIS frameworks, and graphics rendering libraries optimized for large-scale city visualizers.

- [CesiumJS](https://github.com/CesiumGS/cesium) — Open-source JavaScript library for creating world-class 3D globes and 3D spatial visualizers in the web browser.
- [loaders.gl](https://github.com/visgl/loaders.gl) — Suite of framework-agnostic loaders for geospatial formats including 3D Tiles, CityGML, and point clouds.
- [deck.gl](https://github.com/visgl/deck.gl) — High-performance WebGL-based visualization framework designed for large-scale spatial and urban dataset rendering.
- [iTwin.js](https://github.com/iTwin/itwinjs) — Open-source platform for creating, visualizing, and querying digital twin applications for infrastructure assets.

## Urban Simulation & Analytics Engines

Simulation packages and analytical engines for modeling urban microclimates, traffic mobility, building energy usage, and flood risks.

- [CityScope](https://github.com/CityScope) — Open-source urban simulation platform developed by MIT Media Lab for interactive urban planning and scenario analysis.
- [SUMO (Simulation of Urban MObility)](https://github.com/eclipse-sumo/sumo) — Open-source, highly portable, microscopic and continuous road traffic simulation package designed to handle large networks.
- [CityEnergyAnalyst (CEA)](https://github.com/architecture-building-systems/CityEnergyAnalyst) — Open-source urban building energy simulation tool designed to analyze energy optimization scenarios for cities.
- [OpenFOAM](https://github.com/OpenFOAM/OpenFOAM-dev) — Open-source computational fluid dynamics (CFD) software used for urban microclimate, wind tunnel, and air quality simulations.

## IoT & Real-Time Sensor Integration

Protocols, streaming backends, and spatial data brokers for connecting real-time IoT feeds to digital twin representations.

### Sensor Networks & Telemetry

- [OGC SensorThings API Engine](https://github.com/FraunhoferIOSB/FROST-Server) — Open-source server implementation of the OGC SensorThings API standard for managing IoT sensor metrics.
- [ThingsBoard](https://github.com/thingsboard/thingsboard) — Open-source IoT platform for data collection, visualization, and device management in smart city infrastructure deployments.

### Open Data & API Integration

- [FIWARE Context Broker](https://github.com/telefonicaid/fiware-orion) — Open-source component enabling real-time context data management for smart cities and digital twin architectures.
